*glean.txt*  git diff reviewer

See README.md in the plugin directory for commands, keymaps and setup.

:Glean [open {base}]                                             *:Glean*
    Open a live review of {base} (default: `default_base`) plus the dirty
    work tree.

:Glean toggle-mark                                   *:Glean-toggle-mark*
    In a file buffer, mark or unmark the hunk (or range) seen.

:Glean toggle-gutter                               *:Glean-toggle-gutter*
    Turn the sign-column projection on or off everywhere.
